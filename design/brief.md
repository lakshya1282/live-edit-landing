# Brief: live-edit

## 1. What it is
A website for `live-edit`, an Antigravity skill that adds a direct click-to-edit overlay layer on localhost websites and writes modifications straight back into the developer's source code (and queues structural changes for the AI agent).

## 2. Audience
Developers, frontend engineers, design engineers, and creative coders who build sites with AI coding agents (Antigravity) and are fed up with writing long-winded chat prompts for minor text and layout tweaks. They value speed, surgical precision, local-first privacy, and zero fluff.

## 3. Feeling in the first 3 seconds
Minimalist architectural purity and optical liquid glass clarity. Pristine white canvas, razor-sharp black ink typography, tactile frosted glass surfaces with specular rim reflections, and immediate kinetic proof of the in-situ editing workflow.

## 4. Single goal
Make developers install and start using `live-edit` immediately by showing the visceral difference between painful chat prompting and 1-second in-situ editing.

## 5. What it must never look like
- No AI slop: no purple/blue/pink aurora gradients, no glowing ambient blobs, no generic centered template with 3 cards.
- No second-gen AI slop: no near-black + fake gold, no serif + stretched mono timestamps/fake coordinates.
- No low-contrast washed out grays: pure crisp black ink typography with surgical legibility.
- No fake non-working mockup: the live-edit demonstration must animate the real workflow with real UI precision and allow user interaction.

## 6. Stack & Tech
Clean modern web architecture: HTML5, CSS3 with advanced light-mode liquid glassmorphism tokens (optical refraction, specular rim caustics, physical frosted glass backdrop-filters, subtle drop shadows), JavaScript with GSAP and Lenis smooth scrolling, and interactive canvas/DOM simulation.
