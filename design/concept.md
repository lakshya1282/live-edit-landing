# Concept: The Interactive Living Glass Inspection Table

## 1. Idea Burn
- Idea 1 (Burned): Standard IDE dark mode screen with mock VSCode tabs.
- Idea 2 (Burned): Split screen with terminal on left and mock browser on right.
- Idea 3 (Selected): **The Interactive Living Glass Inspection Table.**
  The landing page itself embodies the live-edit experience: pure liquid glass surfaces, tactile direct-manipulation, and an active in-page simulator where visitors witness the live-edit loop animated in real time or take the wheel themselves.
- Idea 4: Publisher's Archival Proofing Table with galley proofs and stamp tools.
- Idea 5: Floating Command HUD with radar pings and AST branch trees.

## 2. Big Idea in One Sentence
This site is an **Interactive Living Glass Inspection Table** that turns passive reading into kinetic proof—letting developers watch and test the live-edit loop directly in the browser while liquid glass panels reveal real AST file writes and Git diffs.

## 3. Three Memorable Moments
1. **The Hero Live-Edit Simulation Stage:** An animated browser viewport running on `localhost:4321`. A simulated cursor navigates to a card, double-clicks the heading, edits the text in-place, clicks Save (Ctrl+S), and watches the bottom glass HUD flash green as `✓ src/Branches.jsx:42 written` appears. Visitors can toggle into "Sandbox Mode" to click, edit, and duplicate cards themselves!
2. **The "Click vs Describe" Race Matrix:** An interactive comparative friction test showing the 45-second pain of typing a verbose AI chat prompt versus the 2-second thrill of clicking and saving on the page.
3. **The Giant Expanding Feature Folio:** A tectonic index where every capability (click-select, inline edit, card duplication, button state, source matching, AST resolution) unfolds into an interactive liquid glass pane.
