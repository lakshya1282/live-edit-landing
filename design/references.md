# Reference Scan

## 1. Linear.app (Productivity / Developer Tools)
- Concept: The gold-standard in mechanical developer efficiency and optical precision.
- Fonts: Custom geometric sans + high-legibility monospace.
- Palette: Smoked obsidian glass (#0b0d11), razor-sharp 1px neutral borders, cyan/mint accents.
- Motion: Snappy 200-300ms easing, instant keyboard shortcuts, subtle specular sheen.
- Craft detail: Inset specular highlight borders (`inset 0 1px 0 rgba(255,255,255,0.12)`).

## 3. Raycast.com (Developer Mac Utility)

## 4. Cron / Notion Calendar (Time / Spatial Interface)
- Concept: Direct manipulation canvas where items can be clicked, dragged, and edited in-situ.
- Fonts: Rounded grotesque with approachable warmth.
- Palette: Crisp slate with translucent hover overlays.
- Motion: Seamless inline morph from static label to editable input box.
- Craft detail: Direct cursor feedback and instant local-first state commitment.

### Craft Synthesis (under 120 words)
The best modern developer tools avoid generic gradient slop and fake glowing blobs. They win through **tactile optical realism**: crisp 1px borders with specular highlights, genuine glass refraction (`backdrop-filter: blur`), instant keyboard feedback, and immediate kinetic proof. Overused tropes today include purple aurora gradients, vague floating 3D spheres, and non-functional screenshots. The gap `live-edit` owns is **living tactile verification**: an interactive in-browser simulator where developers can see and touch the live-edit loop directly on the landing page, feeling the exact speed gain of editing code through the DOM.
