The Problem

Small changes should not need a paragraph of instructions.

You are building with an AI agent. The layout is 90% right. Now you need a new heading, a different opening time on one card, one button turned off. Describing each tweak in chat is slower than just clicking it. live-edit lets you click it, then writes the change into the right file.

Workflow

Three steps. No setup project.

01

Install

Run one command in your project root. It adds the skill, an npm run live script, and a .gitignore line.

$ node ../live-edit/skills/live-edit/scripts/live.mjs init
02

Run

Start your dev server, then npm run live. Open localhost:4321. Your site appears with the editor on top.

$ npm run live
03

Edit and save

Click anything, change it, press Save. Text edits are written straight into your source. Adds, deletes and button changes go to your agent, which applies them in your code style.

→ Press Ctrl+S to save to source Ctrl+S
Capabilities

What you can change on the page

Explore the complete eight-part operational capability matrix of live-edit.

01

Click to select

Hover to highlight, click to select. Jump from a title up to its card or section with Parent.

When live-edit is active, every DOM element gains an inspectable bounding box. Hovering illuminates a crisp dashed boundary. Clicking reveals the floating liquid glass toolbar with directional traversal:

  • Parent ↑: Climbs the DOM tree from text node to wrapping <div class="card"> or <section>.
  • Child ↓: Descends into the first inner text or interactive leaf node.
<h3 class="title">
Downtown Flagship Parent ↑
02

Inline text editing

Double-click any title, subtitle or paragraph and type. Enter confirms, Esc cancels.

No modals, no complex form fields. Just double-click the copy directly in the flow of your layout. The element morphs into an in-situ input box with native typing feel, caret controls, and instant layout reflow preview.

Supports heading tags (h1-h6), paragraphs, spans, labels, and button labels.

Open until 10 PM Late Hours
Enter confirms · Esc cancels
03

Duplicate and delete cards

Add a card by duplicating one. Remove a card in one click. Undo if you slip.

Need a fourth pricing tier, or an extra testimonial? Select the whole card with Parent ↑, then press Duplicate. The clone is injected immediately, allowing you to double-click and customize its content.

When saved, Antigravity synthesizes the new JSX element or appends the item to your existing JSON/data array while matching your exact code style.

Card A (Existing)
+ Card B (Duplicated)
04

Button state

Enable or disable any button and save the state into your code.

Select any button element to reveal the contextual Enable / Disable toggle. Toggle the disabled visual state instantly, hit save, and live-edit dispatches the change to your agent to set the disabled attribute or modify the controlling React/Vue state variable.

disabled prop updated
05

Writes to your source

Text edits are matched to the right file and line in JSX, TSX, HTML, Vue, Svelte, Astro, MDX and JSON.

live-edit does not use a fake headless database. It locates the exact text in your local files using an AST-aware fuzzy matching algorithm that handles whitespace normalization, JSX bracket splits, and HTML entities (&apos;, &amp;).

✓ Zero guessing on ambiguous strings

// src/Branches.jsx:42
<h3>Downtown Flagship</h3>
06

Works with your dev server

A local proxy sits in front of Next.js, Vite or any dev server. Hot reload keeps working.

No bundler plugins to configure. live.mjs runs a lightweight reverse proxy on port 4321 that forwards all HTTP and WebSocket traffic to your upstream dev server (Vite, Next.js, Astro, Remix, Webpack). Fast Refresh and HMR remain 100% active.

Next.js (:3000) ← Proxy (:4321) → Browser
07

Always shows what happened

After Save, a panel lists every file and line written, and every change waiting for the agent.

Total transparency. After every save, a floating telemetry drawer itemizes written files with line numbers. If an item needs agent assistance or has multiple matches, it is categorized clearly:

  • ✓ src/File:line — Written directly.
  • Δ queued — Structural change waiting for agent.
  • Δ notfound — Text is from CMS or API.
✓ src/Branches.jsx:42

08

Local and private

Binds to 127.0.0.1. Writes need a per-session token. Nothing leaves your machine.

Zero telemetry, zero external network requests, zero accounts. The proxy exclusively binds to 127.0.0.1. Each edit session generates an ephemeral cryptographic authentication token to prevent unauthorized writes from other tabs.

Quickstart

Install live-edit in two minutes

Add to any web project with a dev server. No dependencies to add to your app.

# Clone the skill repo to your computer
$ git clone https://github.com/lakshya1282/live-edit.git
# In your website project root:
$ cd your-website
$ node ../live-edit/skills/live-edit/scripts/live.mjs init
# Copies skill to .agent/skills/live-edit/ & adds npm run live
# Terminal 1: Start your normal dev server
$ npm run dev
# Terminal 2: Start the live-edit proxy
$ npm run live
# Open http://localhost:4321 & tell Antigravity: "start live-edit"
live.mjs init # Installs skill & adds npm run live
live.mjs start [--target URL] [--port N] # Starts editor proxy (default 4321)
live.mjs wait [--timeout SECS] # Waits for queued agent changes
live.mjs pending # Inspects pending queue
live.mjs done [id...] # Clears completed items
--target http://localhost:5173 Specify upstream dev server URL if not auto-detected
--port 4400 Set custom proxy port (recommended for Astro projects)
